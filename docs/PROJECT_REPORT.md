# CAMPUSMATE – STUDENT PRODUCTIVITY MANAGER

## 1. Introduction
CampusMate is a Python-based desktop application designed to help students organise their academic activities in one place.

## 2. Problem Statement
Students often manage assignments, attendance and study notes separately. CampusMate provides a single application to manage these activities easily.

## 3. Objectives
- Manage academic assignments.
- Track daily attendance.
- Calculate attendance percentage.
- Save and manage study notes.
- Export data into CSV files.

## 4. Modules

**Module 1: Dashboard**
Displays total tasks, pending tasks, completed tasks and attendance percentage.

**Module 2: Task Management**
Allows users to add, complete, filter and delete academic tasks.

**Module 3: Attendance Management**
Records subject-wise attendance and calculates the overall percentage.

**Module 4: Quick Notes**
Allows users to create, edit and delete study notes.

**Module 5: Data Export**
Exports tasks, attendance and notes into CSV files.

## 5. Technologies Used
- Python 3
- Tkinter
- SQLite Database
- CSV Module

## 6. Software Requirements
- Windows / Linux operating system
- Python 3.8 or later
- Computer or laptop

## 7. Database Design
The application uses three database tables:

1. Tasks
2. Attendance
3. Notes

## 8. Advantages
- Easy to use.
- Saves academic information locally.
- Reduces manual record keeping.
- Provides organised student information.
- Works without an internet connection.

## 9. Future Enhancements
- Student login system.
- Cloud database integration.
- Notification and reminders.
- Graphical attendance reports.
- Mobile application support.

## 10. Conclusion
CampusMate demonstrates the practical use of Python programming, GUI development and database management. It provides a simple solution for managing student academic activities.
